## 测试执行顺序

### 单元测试执行顺序

1. 工具函数测试（无依赖）
2. Store测试（依赖工具函数）
3. 组件测试（依赖Store和工具函数）
4. API测试（依赖Mock）

### 集成测试执行顺序

1. Auth集成测试（用户认证）
2. Category集成测试（分类管理）
3. Item集成测试（物品管理）
4. Order集成测试（订单管理）
5. Review集成测试（评价管理）

### E2E测试执行顺序

1. login.spec.js（登录流程）
2. user-flows.spec.js（用户流程）
3. items.spec.js（物品流程）
4. orders.spec.js（订单流程）
5. browser-compat.spec.js（浏览器兼容性）
