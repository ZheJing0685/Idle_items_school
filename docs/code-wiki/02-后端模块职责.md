# 后端模块职责

## 1. 后端架构概述

后端采用标准三层架构，基础包路径为 `com.idleitems.school`。

```
Controller → Service → Repository → MySQL
     ↑
   Filter / Aspect / Security (横切关注点)
```

入口类：`IdleItemsSchoolApplication.java`

---

## 3. service 包 — 业务逻辑层

| 服务 | 实现类 | 职责 |
|------|--------|------|
| AuthService | AuthServiceImpl | 用户注册（校验唯一性、BCrypt 加密）、登录（验证凭据、生成 JWT、记录登录信息）、登出（Token 黑名单）、刷新令牌、获取/更新用户信息、修改密码、上传头像 |
| ItemService | — | 物品 CRUD、分页查询（支持分类/价格/状态/排序筛选）、热门物品查询（基于浏览量和收藏量）、物品状态管理（上架/下架/售出）、图片上传/删除、缓存管理 |
| OrderService | — | 订单创建（校验物品状态、防止自买自卖）、状态流转（支付→发货→收货→完成）、取消订单（30 分钟超时自动取消）、退款申请/处理、订单评价、订单统计 |
| ChatService | — | 创建聊天会话、发送/接收消息、消息已读标记、聊天列表查询（按最后消息时间排序） |
| CategoryService | — | 分类 CRUD、分类树构建（最多 3 级）、分类缓存（1 小时） |
| FavoriteService | — | 收藏/取消收藏、收藏列表查询、收藏状态检查、收藏计数同步 |
| ReviewService | — | 评价 CRUD、按物品/用户查询评价、评价统计 |
| UserService | — | 用户信息管理、用户状态管理（启用/禁用/封禁）、用户统计 |
| UserInfoService | — | 用户详细信息查询、用户资料更新 |
| FileService | FileServiceImpl | 文件上传（图片验证、压缩、水印）、文件删除、文件 URL 生成 |
| AdminLogService | — | 管理员操作日志记录、日志查询 |
| LogAnalysisService | — | 日志分析（按时间/操作类型/管理员统计）、日志导出、日志清理 |
| ImageAnalysisService | — | 图片 AI 分析（物品类型、品牌、颜色识别）、分析结果存储 |

## 8. security 包 — 安全模块

### JwtUtil

JWT 令牌工具类：

| 功能 | 说明 |
|------|------|
| 签名算法 | HMAC-SHA |
| Token 有效期 | 1 小时（3600000ms） |
| Token 内容 | userId（subject）、username、role |
| 核心方法 | generateToken, validateToken, getUserIdFromToken, getUsernameFromToken, getRoleFromToken, isTokenExpired |

## 9. filter 包 — 过滤器

### XssFilter

XSS 攻击防护过滤器：
- 检测 XSS 攻击模式（script 标签、javascript: 协议、事件处理器等）
- 使用 OWASP Encoder 进行 HTML 编码
- 支持 JSON 请求体过滤（通过 XssHttpServletRequestWrapper 包装）

### RateLimitFilter

基于 Redis 的滑动窗口限流过滤器：
- 默认配置：每分钟 60 次请求
- 按 IP + URI 维度限流
- 超限返回 HTTP 429 状态码

---

## 10. aspect 包 — AOP 切面

### PermissionAspect

权限校验切面：
- 拦截标注了 `@RequireRole` 注解的方法
- 从请求属性中获取 userId
- 查询用户角色并验证是否满足要求
- 权限不足时抛出 403 异常

---

## 11. annotation 包 — 自定义注解

### @RequireRole

标记方法所需角色，支持单角色和多角色：

```java
@RequireRole(User.Role.ADMIN)                          // 仅管理员
@RequireRole({User.Role.ADMIN, User.Role.SUPER_ADMIN}) // 管理员或超级管理员
```

## 12. cache 包 — 缓存服务

### CacheService

通用 Redis 缓存服务，提供以下操作：

| 操作类型 | 方法 |
|----------|------|
| 基本操作 | set, get, delete, exists |
| 过期管理 | expire, getExpire |
| 计数器 | increment, decrement |
| 集合操作 | addToSet, getSet, isMemberOfSet, removeFromSet |
| 批量删除 | deletePattern（使用 SCAN 命令替代 KEYS，避免阻塞） |

## 13. task 包 — 定时任务

### OrderTimeoutTask

订单超时自动取消任务：
- 执行频率：每 5 分钟（300000ms）
- 功能：检查并取消超时订单（30 分钟未支付）
- 日志：记录取消的订单数量

| 收藏状态 | favorite:status:{userId}:{itemId} | 30 分钟 |
| 统计数据 | statistics:{type}:{period} | 5 分钟 |

## 16. 模块依赖关系总览

```
Controller ──→ Service ──→ Repository ──→ Entity
    │              │
    │              ├──→ CacheService (Redis)
    │              ├──→ FileService (文件上传)
    │              └──→ CacheManager (缓存策略)
    │
    ├──→ DTO (请求/响应)
    └──→ GlobalExceptionHandler (异常处理)

Security (JwtUtil) ←── WebSecurityConfig ←── Filter (XSS/限流)
                                              Aspect (PermissionAspect) ←── @RequireRole
                                              Task (OrderTimeoutTask) ←── OrderService
```
