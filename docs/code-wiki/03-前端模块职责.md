# 前端模块职责

## 1. 前端架构概述

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue | 3.5.32 | 核心框架（Composition API） |
| Vite | 8.0.4 | 构建工具 |
| Pinia | 3.0.4 | 状态管理 |
| Element Plus | 2.13.7 | UI 组件库 |
| Vue Router | 4.6.4 | 路由管理 |
| Axios | 1.15.0 | HTTP 客户端 |

入口文件 `src/main.js`：创建 Vue 应用，注册 ElementPlus、Router、Pinia。

根组件 `src/App.vue`：三段式布局 — Header + router-view（带 fade 过渡动画）+ Footer。

### 路由守卫逻辑

**beforeEach**：
1. 设置页面标题（`document.title = to.meta.title`）
2. 检查目标路由是否需要认证（`meta.requiresAuth`）
3. 未登录 → 保存当前路径到 localStorage → 跳转 /login
4. 需要管理员权限 → 每次刷新用户信息验证 Token 和角色 → 非管理员跳转首页
5. 普通认证路由 → 仅在用户信息缺失时获取

**afterEach**：平滑滚动到页面顶部

## 5. store 包 — Pinia 状态管理

文件：`src/store/index.js` — 导出 pinia 实例和三个 Store。

### 5.1 user store（modules/user.js）

**State**：

| 字段 | 类型 | 说明 |
|------|------|------|
| token | ref(string) | JWT Token |
| refreshToken | ref(string) | 刷新令牌 |
| user | ref(object) | 用户信息 |
| lastLoginTime | ref(string) | 最后登录时间 |
| rememberMe | ref(boolean) | 记住我 |
| loading | ref(boolean) | 加载状态 |

**Computed**：

| 字段 | 说明 |
|------|------|
| isLoggedIn | 是否已登录（`!!token`） |
| isAdmin | 是否管理员（role === 'ADMIN' 或 'SUPER_ADMIN'） |
| isVerified | 是否已实名认证 |

**Actions**：

| 方法 | 说明 |
|------|------|
| login(username, password, remember) | 用户登录，存储 Token 和用户信息，启动 Cookie 检查 |
| register(userData) | 用户注册 |
| logout() | 用户登出，清除所有认证数据 |
| getCurrentUser() | 获取当前用户信息（从后端 /auth/me） |
| updateProfile(profileData) | 更新个人资料 |

**特殊机制**：
- Cookie 过期检测：每 30 秒轮询检查 Cookie 中的 Token 是否存在
- 强制登出：Cookie 过期时弹窗提示并跳转登录页
- 页面可见性检查：页面重新可见时立即检查 Token 有效性
- Token 双存储：内存 + Cookie（7 天过期）

### 5.2 item store（modules/item.js）

**State**：

| 字段 | 类型 | 说明 |
|------|------|------|
| items | ref(array) | 物品列表 |
| total | ref(number) | 总数 |
| loading | ref(boolean) | 加载状态 |
| hotItems | ref(array) | 热门物品 |
| currentItem | ref(object) | 当前物品详情 |
| searchResults | ref(array) | 搜索结果 |
| searchTotal | ref(number) | 搜索总数 |
| userItems | ref(array) | 用户物品列表 |
| userItemsTotal | ref(number) | 用户物品总数 |

**Actions**：

| 方法 | 说明 |
|------|------|
| fetchItems(params) | 获取物品列表（分页、筛选） |
| fetchHotItems() | 获取热门物品 |
| searchItems(keyword, page, size, sortBy) | 搜索物品 |
| getItem(id) | 获取物品详情 |
| createItem(itemData) | 创建物品（清除缓存） |
| updateItem(id, itemData) | 更新物品（清除缓存） |
| offShelfItem(id) | 下架物品（清除缓存） |
| fetchUserItems(status, page, size) | 获取用户物品列表 |
| uploadImage(formData) | 上传图片 |

### 5.3 cart store（modules/cart.js）

## 6. api 包 — API 服务层

### 6.1 config/axios.js — Axios 实例配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| baseURL | /api | API 基础路径 |
| timeout | 15000ms | 请求超时 |
| withCredentials | true | 携带 Cookie |

**Token 管理**：内存 + Cookie 双存储
- `setToken(token)` — 写入内存和 Cookie（7 天过期）
- `getToken()` — 从内存读取
- `clearToken()` — 清除内存和 Cookie

**请求拦截器**：自动添加 `Authorization: Bearer {token}` header

**响应拦截器**：统一错误处理

| 状态码 | 处理 |
|--------|------|
| 401 | 清除认证数据，弹窗提示登录过期，跳转 /login |
| 403 | 提示权限不足 |
| 404 | 提示资源不存在 |
| 500 | 提示服务器错误 |
| 超时 | 提示请求超时 |
| 网络错误 | 提示网络连接失败 |

### 6.2 config/paths.js — API 路径常量

| 模块 | 路径 |
|------|------|
| AUTH | /auth/login, /auth/register, /auth/me, /auth/refresh |

| CATEGORY | /categories, /categories/tree |

| 服务 | 文件 | 方法 | 缓存策略 |

| user | services/user.js | 用户相关 API | — |
| review | services/review.js | 评价相关 API | — |
| verification | services/verification.js | 实名认证 API | — |

### 6.4 index.js — API 统一导出

聚合所有服务模块，统一导出 `api` 对象，包含：
- 各模块服务（auth, item, category, favorite, user, verification, review, order, admin）
- Token 管理方法（setToken, getToken, clearToken）
- 缓存管理（clearCache, clearAllCache）
- 未授权处理（setUnauthorizedHandler）
