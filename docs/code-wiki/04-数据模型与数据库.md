# 数据模型与数据库

## 1. 数据库概述

| 配置项 | 值 |
|--------|-----|
| 数据库 | MySQL 8.0 |
| 字符集 | utf8mb4 + utf8mb4_unicode_ci |
| 存储引擎 | InnoDB（支持事务和外键） |
| 主键策略 | BIGINT AUTO_INCREMENT |
| 软删除 | 全表统一使用 is_deleted TINYINT(1) |
| 审计字段 | create_by / update_by / created_at / updated_at |
| 迁移工具 | Flyway 风格版本化脚本（V1-V16） |

---

## 3. 表间关系

```
users (1) ──────→ (N) items          [user_id]
users (1) ──────→ (N) orders         [buyer_id, seller_id]
users (1) ──────→ (N) favorites      [user_id]
users (1) ──────→ (N) reviews        [reviewer_id, reviewed_user_id]
users (1) ──────→ (N) chats          [buyer_id, seller_id]
users (1) ──────→ (N) verification_records [user_id]
users (1) ──────→ (N) admin_logs     [admin_id]
users (1) ──────→ (N) disputes       [applicant_id, respondent_id]

categories (1) ──→ (N) items          [category_id]
categories (1) ──→ (N) categories     [parent_id] (自引用)

items (1) ──────→ (N) orders          [item_id]
items (1) ──────→ (N) favorites       [item_id]
items (1) ──────→ (N) reviews         [item_id]
items (1) ──────→ (N) item_images     [item_id]
items (1) ──────→ (N) item_tags       [item_id]
items (1) ──────→ (N) image_analysis  [item_id]

orders (1) ─────→ (N) reviews         [order_id]
orders (1) ─────→ (N) disputes        [order_id]

chats (1) ──────→ (N) chat_messages   [chat_id]
```

## 4. Flyway 迁移脚本概览

| 版本 | 文件名 | 内容概述 |
|------|--------|----------|
| V1 | V1__initial_schema.sql | 初始表结构（users, categories, items, orders 等 14 张核心表） |
| V2 | V2__add_core_fields.sql | 添加核心字段（逻辑删除 is_deleted、审计字段 create_by/update_by、用户信用分/登录信息、订单金额字段） |
| V3 | V3__add_optional_fields.sql | 添加可选字段（用户性别/生日/简介、物品品牌/交易方式、订单备注、分类层级/路径、评价/收藏/聊天扩展字段） |
| V4 | V4__add_new_tables.sql | 添加 5 张新表（user_addresses, user_follows, notifications, system_configs, operation_logs） |
| V5 | V5__data_initialization.sql | 数据初始化（默认值填充、系统配置、默认分类数据 6 大类 + 18 子类、管理员用户、分类路径初始化） |
| V6 | V6__add_image_fields.sql | 添加物品图片字段（cover_image, images） |
| V7 | V7__normalize_order_statuses.sql | 规范化订单状态（TINYINT → VARCHAR(30)，数值映射为字符串常量） |
| V8 | V8__align_runtime_schema.sql | 对齐运行时 Schema（所有枚举字段从 TINYINT 转为 ENUM 类型：role, status, item_condition, order_status, payment_method 等） |
| V9 | V9__add_performance_indexes.sql | 添加性能索引（admin_logs, orders, items, users 表） |
| V10 | V10__add_table_and_column_comments.sql | 添加表和列的中文注释（COMMENT） |
| V11 | — | 已跳过（不存在） |
| V12 | V12__add_category_status.sql | 添加分类状态字段（status TINYINT(1)） |
| V13 | V13__redesign_categories_table.sql | 重新设计分类表（创建 categories_new、迁移数据、重命名表） |
| V14 | V14__add_composite_indexes.sql | 添加复合索引（chat_messages, chats, users, item_images, item_tags, notifications, favorites, reviews, image_analysis, verification_records） |
| V15 | V15__align_orders_schema.sql | 对齐订单 Schema（确保 deliver_time, tracking_number, shipping_company 列存在，统一 VARCHAR 长度） |
| V16 | V16__ensure_admin_user.sql | 确保管理员用户存在（INSERT ON DUPLICATE KEY UPDATE） |
