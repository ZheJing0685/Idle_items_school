# 运行与部署

## 1. 环境要求

### 本地开发环境

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17+ | 后端运行环境 |
| Maven | 3.8+ | 后端依赖管理与构建 |
| Node.js | 20+ | 前端运行环境 |
| npm | 10+ | 前端依赖管理 |
| MySQL | 8.0+ | 数据库 |
| Redis | 6.0+ | 缓存（可选，开发环境可不启动） |

### Docker 环境

| 工具 | 版本要求 |
|------|----------|
| Docker | 20.10+ |
| Docker Compose | 2.0+ |

## 2. 本地开发环境搭建

### 2.1 克隆项目

```bash
git clone <repository-url>
cd Idle_items_school
```

### 2.2 数据库准备

1. 启动 MySQL 服务
2. 创建数据库：

```sql
CREATE DATABASE idle_items_school CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

3. 数据库表结构由 Flyway 迁移脚本在应用启动时自动创建

### 2.3 后端启动

```bash
cd backend
mvn clean install
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

| 项目 | 值 |
|------|-----|
| 端口 | 7000 |
| 上下文路径 | /api |
| Swagger 文档 | http://localhost:7000/api/swagger-ui.html |
| 健康检查 | http://localhost:7000/api/test/health |

### 2.4 前端启动

```bash
cd frontend
npm install
npm run dev
```

| 项目 | 值 |
|------|-----|
| 端口 | 5173 |
| 访问地址 | http://localhost:5173 |
| API 代理 | 通过 Vite 代理转发到后端 /api |

### 2.5 Redis（可选）

```bash
redis-server
```

默认端口：6379

## 4. Docker 部署

### 4.1 Docker Compose 架构

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   frontend  │    │   backend   │    │    mysql    │
│  Nginx:80   │───→│  Java:8080  │───→│  MySQL:3306 │
│  Vue SPA    │    │  Spring Boot│    │  数据持久化  │
└─────────────┘    └─────────────┘    └─────────────┘
```

| 服务 | 镜像/构建 | 端口 | 依赖 |
|------|----------|------|------|
| mysql | mysql:8.0 | 3306:3306 | 无 |
| backend | 自定义构建 (./backend/Dockerfile) | 8080:8080 | mysql |
| frontend | 自定义构建 (./frontend/Dockerfile) | 80:80 | backend |

### 4.2 启动命令

```bash
# 构建并启动所有服务
docker-compose up -d --build

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 停止并删除数据卷
docker-compose down -v
```

### 4.3 后端 Dockerfile

- 基础镜像：openjdk:17-jdk-slim
- 复制 JAR 包，暴露端口 7000

### 4.4 前端 Dockerfile

多阶段构建：
1. **构建阶段**：node:14-alpine → npm install → npm run build
2. **运行阶段**：nginx:alpine → 复制构建产物 + nginx.conf

### 4.5 Nginx 配置

- 监听端口 80
- `/` → 静态文件 + SPA fallback（try_files $uri $uri/ /index.html）
- `/api` → 反向代理到 backend:8080/api

### 4.6 已知问题

| 问题 | 说明 |
|------|------|
| MySQL root 密码硬编码 | 密码为 "root"，存在安全隐患 |
| 前端 Dockerfile Node 版本 | 使用 node:14-alpine，实际需要 node:20+ |
| 无健康检查 | depends_on 仅保证启动顺序，不保证服务就绪 |
| 无 Redis 服务 | 后端已配置 Redis，但 docker-compose 未包含 Redis 容器 |
| 敏感信息明文 | 数据库密码等直接写在 docker-compose.yml 中 |

## 5. CI/CD 流水线

### 5.1 主流水线（.github/workflows/ci-cd.yml）

触发条件：push/PR 到 main/develop 分支

| 阶段 | 内容 | 依赖 |
|------|------|------|
| frontend-tests | npm ci → npm run test:coverage → npx playwright test | 无 |
| backend-tests | mvn package → mvn test | 无 |
| build | 前后端分别构建，上传 artifact（保留 7 天） | 上述两个测试 |
| deploy | 仅 main 分支触发，目前为占位符 | build |

### 5.2 后端独立测试（.github/workflows/backend-tests.yml）

- 仅在 backend/** 路径变更时触发
- 构建 + 测试 + 上传 surefire 报告和 JaCoCo 覆盖率报告（保留 14 天）

### 5.3 代码质量扫描（.github/workflows/qodana_code_quality.yml）

- JetBrains Qodana 静态代码分析
- PR 和 main 分支 push 时触发
- 支持 PR 评论和注解

## 6. 常用运维命令

### 后端

```bash
# 构建 JAR
cd backend && mvn clean package -DskipTests

# 运行测试
cd backend && mvn test

# 查看后端日志
tail -f backend/logs/application.log
```

### 前端

```bash
# 构建生产版本
cd frontend && npm run build

# 运行单元测试
cd frontend && npm run test:unit

# 运行 E2E 测试
cd frontend && npm run test:e2e

# 代码检查
cd frontend && npm run lint
```

### 数据库

```bash
# 连接数据库
mysql -h localhost -P 3306 -u root -p idle_items_school

# Docker 中连接
docker exec -it mysql-idle-items mysql -u root -proot idle_items_school
```
