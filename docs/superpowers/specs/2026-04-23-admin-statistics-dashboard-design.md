# 后台管理统计仪表盘设计方案

**版本：** 1.0
**日期：** 2026-04-23
**状态：** 待审核

***

## 1. 概述

### 1.1 项目背景

为闲置物品校园交易平台后台管理系统开发数据统计仪表盘，帮助管理员快速掌握平台交易核心指标。

### 1.2 核心功能

- 交易数据统计：订单数、交易额、订单状态分布
- 多维度图表展示：趋势折线图、状态饼图
- 时间范围筛选：今日/本周/本月/自定义日期

### 1.3 设计原则

- 数据密度优先：网格布局，最大化信息展示
- 操作简便：时间筛选器一键切换
- 性能优先：按需加载，减少不必要的数据请求

***

### 3.2 响应式策略

- **大屏 (>1200px)**: 4列统计卡片 + 2列图表
- **中屏 (768-1200px)**: 2列统计卡片 + 1列图表
- **小屏 (<768px)**: 1列统计卡片 + 图表堆叠

## 4. API 接口

### 4.1 获取统计数据

```
GET /api/admin/statistics/dashboard
```

**请求参数：**

| 参数        | 类型     | 必填 | 说明                      |
| --------- | ------ | -- | ----------------------- |
| timeRange | string | 是  | today/week/month/custom |
| startDate | string | 否  | 自定义开始日期 (yyyy-MM-dd)    |
| endDate   | string | 否  | 自定义结束日期 (yyyy-MM-dd)    |

**响应格式：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "totalOrders": 1234,
    "totalAmount": 56789.00,
    "pendingOrders": 23,
    "completedOrders": 1211,
    "orderTrend": [
      {"date": "2026-04-17", "count": 45},
      {"date": "2026-04-18", "count": 52},
      ...
    ],
    "orderStatusDistribution": {
      "pending": 23,
      "processing": 0,
      "completed": 1211,
      "cancelled": 0
    },
    "recentOrders": [
      {
        "id": 1001,
        "buyerName": "张三",
        "sellerName": "李四",
        "amount": 120.00,
        "status": "COMPLETED",
        "createdAt": "2026-04-23T10:30:00"
      }
    ]
  }
}
```

## 5. 组件设计

### 5.1 组件结构

```
src/views/admin/
├── Statistics.vue          # 主页面组件
├── components/
│   ├── StatCard.vue        # 统计卡片组件
│   ├── OrderTrendChart.vue # 订单趋势图组件
│   ├── OrderStatusPie.vue  # 订单状态饼图组件
│   └── RecentOrdersTable.vue # 最近订单表格组件
```

### 5.2 StatCard 组件

**Props：**

| 属性     | 类型            | 说明   |
| ------ | ------------- | ---- |
| title  | string        | 卡片标题 |
| value  | number/string | 数值   |
| prefix | string        | 前缀符号 |
| suffix | string        | 后缀符号 |
| icon   | string        | 图标名称 |

### 5.3 OrderTrendChart 组件

**Props：**

| 属性   | 类型    | 说明                    |
| ---- | ----- | --------------------- |
| data | array | 趋势数据 \[{date, count}] |

### 5.4 OrderStatusPie 组件

**Props：**

| 属性   | 类型     | 说明                                               |
| ---- | ------ | ------------------------------------------------ |
| data | object | 状态分布 {pending, processing, completed, cancelled} |

## 6. 数据流设计

```
用户选择时间范围
       │
       ▼
Statistics.vue 调用 API
       │
       ▼
获取数据后更新响应式状态
       │
       ├──► StatCard (总订单数/总交易额/待处理/已完成)
       │
       ├──► OrderTrendChart (订单趋势折线图)
       │
       ├──► OrderStatusPie (订单状态饼图)
       │
       └──► RecentOrdersTable (最近订单表格)
```

***

## 7. 错误处理

| 场景       | 处理方式                      |
| -------- | ------------------------- |
| API 请求失败 | 显示 ElMessage 错误提示，保留空数据状态 |
| 数据为空     | 显示"暂无数据"占位符               |
| 网络断开     | 显示重连按钮                    |
