**安全修复详细步骤**：

**步骤1：SQL注入防护**
```
1. 审查所有Repository接口
2. 将动态SQL改为参数化查询
3. 添加输入验证注解
4. 使用ESAPI进行特殊字符过滤
5. 安全测试验证
```

**步骤2：XSS防护**
```
1. 创建XssFilter过滤器
2. 配置Spring Security添加过滤器
3. 添加@XssClean注解到String字段
4. 配置安全响应头（CSP、X-Frame-Options等）
5. 全局测试验证
```

**步骤3：接口限流**
```
1. 引入Redis依赖
2. 配置Redis连接
3. 编写限流Lua脚本
4. 创建@RateLimit注解
5. 应用到登录、注册等接口
```
