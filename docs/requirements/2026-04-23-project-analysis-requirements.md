# 项目系统分析需求文档

## 1. 任务目标

全面分析闲置物品校园交易平台项目系统，包括前端和后端的技术栈、目录结构、启动方式，并深入分析可能存在的逻辑问题。

## 2. 任务范围

### 2.1 分析内容
- **SKILL.md研读**：理解项目所需的技能要求与技术规范
- **前端分析**：目录结构、功能模块、技术栈及版本
- **后端分析**：目录结构、服务模块、技术栈及版本
- **启动方式**：开发环境与生产环境的启动命令、配置文件、环境变量
- **项目结构结论**：目录组织结构、技术栈详情、模块依赖关系、启动流程
- **逻辑问题分析**：业务逻辑、数据流程、模块交互、错误处理等方面的问题

### 2.2 交付物
- 项目结构结论报告
- 系统逻辑问题分析报告

## 3. 约束条件

- **技术约束**：基于现有项目代码和配置文件进行分析
- **时间约束**：在现有环境中完成分析，不进行代码修改
- **输出约束**：使用中文进行分析和报告撰写

## 4. 验收标准

- 全面覆盖前端和后端的技术栈和目录结构
- 准确记录启动方式和配置要求
- 深入分析系统可能存在的逻辑问题
- 报告内容详细、结构清晰、逻辑严谨

## 5. 执行步骤

1. **SKILL.md研读**：读取并分析项目中的SKILL.md文件
2. **前端分析**：梳理前端目录结构和技术栈
3. **后端分析**：梳理后端目录结构和技术栈
4. **启动方式分析**：记录前端和后端的启动命令和配置
5. **项目结构结论**：生成全面的项目结构分析报告
6. **逻辑问题分析**：深入分析系统可能存在的逻辑问题

## 6. 非目标

- 不进行代码修改或优化
- 不进行系统部署或运行
- 不进行性能测试或安全测试
