## 3. 发现的缺陷列表

### 3.1 高风险缺陷
1. **安全组件未测试**
   - **位置：** `JwtTokenBlacklistService.java`, `JwtUtil.java`, `SecurityConfig.java`
   - **问题：** JWT令牌黑名单、令牌生成/验证、安全配置未经过测试
   - **影响：** 可能存在安全漏洞，如令牌伪造、权限绕过
   - **建议：** 添加安全组件的单元测试和集成测试

2. **WebSocket配置未测试**
   - **位置：** `WebSocketConfig.java`, `StompAuthInterceptor.java`
   - **问题：** WebSocket连接认证、消息订阅未测试
   - **影响：** 实时通信功能可能不稳定或存在安全风险
   - **建议：** 添加WebSocket连接和消息处理的测试
