# 登录状态管理测试指南

## 1. Chrome DevTools测试

### 1.1 打开Chrome DevTools
- 在Chrome浏览器中，按 `F12` 或右键点击页面并选择 "检查" 打开DevTools
- 或使用快捷键 `Ctrl+Shift+I` (Windows) 或 `Cmd+Option+I` (Mac)

### 1.2 测试网络请求
1. **Network面板**
   - 点击 "Network" 标签页
   - 勾选 "Preserve log" 选项
   - 尝试登录操作，观察网络请求
   - 检查请求和响应的状态码、请求头、响应体等
   - 验证登录请求是否成功，token是否正确返回

2. **Application面板**
   - 点击 "Application" 标签页
   - 在左侧导航栏中选择 "Local Storage" -> "http://localhost:5173"
   - 检查是否存储了token、user等登录状态数据
   - 验证数据是否正确加密存储

3. **Console面板**
   - 点击 "Console" 标签页
   - 运行测试脚本：
     ```javascript
     import LoginStateTest from './src/utils/loginStateTest.js';
     const test = new LoginStateTest();
     test.runAllTests();
     ```
   - 观察测试结果，检查是否有错误信息

### 1.3 测试场景

#### 场景1：登录成功状态显示
1. 打开登录页面：http://localhost:5173/login
2. 输入测试账号：testuser / test123
3. 点击登录按钮
4. 检查登录后是否正确显示用户头像和用户名
5. 验证Network面板中登录请求是否成功
6. 验证Application面板中是否存储了登录状态数据

#### 场景2：页面刷新状态保持
1. 登录成功后，刷新页面
2. 检查刷新后是否仍然显示登录状态
3. 验证Network面板中是否有获取用户信息的请求
4. 验证Application面板中登录状态数据是否仍然存在

#### 场景3：路由切换状态一致性
1. 登录成功后，在不同路由之间切换（如首页、浏览闲置、个人中心等）
2. 检查在路由切换过程中登录状态是否保持一致
3. 验证Network面板中是否有不必要的重复请求

#### 场景4：会话过期自动处理
1. 登录成功后，在Application面板中修改token为无效值
2. 刷新页面或切换路由
3. 检查是否自动跳转到登录页面
4. 验证登录状态是否已清除

#### 场景5：多标签页状态同步
1. 登录成功后，打开一个新的标签页
2. 在新标签页中登出系统
3. 切换回原标签页，检查登录状态是否已同步清除
4. 验证是否自动跳转到登录页面

#### 场景6：令牌刷新机制
1. 登录成功后，在Application面板中修改lastLoginTime为24小时前
2. 刷新页面或切换路由
3. 检查Network面板中是否有令牌刷新请求
4. 验证令牌是否成功刷新

## 6. 问题排查

### 6.1 常见问题
1. **登录状态未显示**
   - 检查Network面板中登录请求是否成功
   - 检查Application面板中是否存储了登录状态数据
   - 检查控制台是否有错误信息

2. **页面刷新后登录状态丢失**
   - 检查Application面板中localStorage数据是否存在
   - 检查user store中的初始化逻辑
   - 检查路由守卫是否正确处理登录状态

3. **令牌刷新失败**
   - 检查Network面板中刷新令牌的请求是否成功
   - 检查后端refreshToken API是否正常
   - 检查前端refreshToken方法是否正确实现

4. **多标签页状态不同步**
   - 检查storage事件监听器是否正确实现
   - 验证不同标签页是否共享localStorage

### 6.2 调试技巧
- 使用 `console.log()` 在关键位置添加日志
- 使用Chrome DevTools的断点功能调试代码
- 使用 `localStorage.clear()` 清除所有存储数据，重新测试
- 使用无痕模式测试，避免浏览器缓存影响
